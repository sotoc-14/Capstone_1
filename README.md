# Capstone 1: Colorado Sales Analysis

Project Overview

This project analyzes sales performance for EmporiUm, a retail company. My territory is Colorado, managed by Jim Heck in the West Region.

I used SQL to analyze sales data from January 2022 through December 2025 and Excel to visualize store performance.

Tools Used

MySQL Workbench
Microsoft Excel


Total Colorado Revenue: $6,412,632.22

Highest-Performing Store: Store 705 ($917,471.53)
Lowest-Performing Store: Store 715 ($279,268.94)

# Sales Recommendation

I recommend reviewing sales performance at Stores 715, 718, and 702, which generated the lowest total revenue in Colorado.
