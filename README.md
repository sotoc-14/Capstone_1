# Capstone 1: Colorado Sales Analysis

## Project Overview

This project analyzes sales performance for EmporiUm, a retail company. My territory is Colorado, managed by Jim Heck in the West Region.

I used SQL to analyze sales data from January 2022 through December 2025 and Excel to visualize store performance.

## Tools Used

MySQL Workbench

Microsoft Excel

PowerPoint

## Key Findings

Total Colorado Revenue: $6,412,632.22

Highest-Performing Store: Store 705 ($917,471.53)

Lowest-Performing Store: Store 715 ($279,268.94)

### Recommendations

I recommend reviewing sales performance at Stores 715, 718, and 702, as they generated the lowest total revenue in Colorado.

I would also investigate the strategies used by Store 705 to determine whether similar approaches could improve performance at other locations.

Additionally, I recommend exploring opportunities to increase technology sales, as this category accounts for approximately 71% of Colorado's total revenue.
